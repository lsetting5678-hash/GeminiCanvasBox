# 安全守護隊｜互動式校園安全教材

為國小特殊教育學生設計的純前端互動教材。教材包含大型情境圖、教學頁、人物情境動畫、選擇題、OX 練習、語音、教師控制、七關勳章與無個資通關獎狀；不需要學生帳號或雲端資料庫，可部署至 GitHub Pages。

## 本機執行

在專案根目錄執行：

```powershell
node tools/serve-safety-guardian.mjs
```

再用 Chrome 開啟 `http://127.0.0.1:4173/`。

可攜版也可直接雙擊「啟動安全守護隊.bat」，或用 Chrome 開啟 `index.html`。

## 跨裝置使用

整個「安全守護隊」資料夾或 `安全守護隊.zip` 可複製到另一台 Windows 電腦。圖片、人物情境動畫、音效、配樂與獎狀產生功能都放在資料夾內，不需要外部 Gemini 情境連結。

學習進度與語音／音效／配樂設定只儲存在各裝置自己的瀏覽器，不會跟著資料夾移動，也不包含學生姓名、班級、座號或其他個人資料。

## 通關獎狀

完成全部七關後，教材會顯示七枚勳章與通關慶祝畫面，並提供：

- `📄 產生通關獎狀 PDF`
- `🖨 列印獎狀`

獎狀為 A4 橫式，以一面大型盾牌為中心，七枚關卡徽章環繞呈現，並使用芫荽體。姓名、完成日期及教師簽名均保留空白供列印後手寫。PDF 固定命名為 `安全守護隊_通關獎狀.pdf`，不要求或儲存任何學生個資。

## 主要功能

- 七個可自由選擇的安全關卡與本機進度
- 正式 34 題安全題庫：走廊 5 題、排隊 4 題、樓梯 5 題、告知大人 6 題、身體界線 7 題、放學 3 題、陌生人 4 題
- 34 題均使用各自不同的彩色情境圖，題目答案位置固定交錯為第一側 17 題、第二側 17 題
- 七個關卡都採用 7 張獨立人物動作幀，呈現走路、停步、伸手、拒絕、求助等不同姿勢
- 主情境動作序列可停在目前幀、從目前幀繼續，或回到第 1 幀重播
- 主情境題目與圖像選項只在第 7 幀決策停格後出現
- 4 題重要 OX 題使用各自的 4 幀短動畫：走廊有人跑來、樓梯不可推人、餅乾不可交換抱抱、陌生人糖果不可跟隨
- 動態 OX 題在第 4 幀停格後才朗讀題目並顯示圈／叉；同樣支援暫停、繼續與重播
- 每題不同的完整校園情境圖
- 一次一題、無計時、不扣分
- 繁體中文瀏覽器語音朗讀
- 題目、選項、答對與鼓勵式答錯語音
- 暫停、繼續、重聽與重播情境
- 大型 O／X 與圖像選項按鈕
- 音效及背景配樂獨立開關
- 右上角收合式教師控制列與題目列表
- 完成七關後產生無個資 A4 橫式 PDF 獎狀
- 16:9 教室螢幕優先，也可縮放到平板

所有七關的主情境已完成真正人物姿勢變化的圖片序列；4 題重要 OX 使用短動畫，其餘 30 題使用各自不同的靜態彩色情境圖，沒有使用圖片縮放假裝人物動畫。

## GitHub Pages

將專案推送到 GitHub 後，可把 Pages 的來源目錄設定為 `/safety-guardian`，或將此目錄內容放到 Pages 發佈根目錄。

語音使用瀏覽器的 Web Speech API；Chrome 會優先選擇 `zh-TW` 語音。Windows 若沒有台灣中文語音，需先在系統語言／語音設定中安裝。
